# Skills Claude pour importer et entreprendre en Afrique centrale

Trois skills gratuits, en français, pour les importateurs, commerçants et entrepreneurs de la zone CEMAC et de la RDC. Créés par **NELVIS** à partir de plus de 20 ans de fret et de négoce France–Chine–Afrique.

| Skill | Ce qu'il fait |
|---|---|
| `rentabilite-import-afrique` | Une offre fournisseur → prix du marché à Brazzaville, Pointe-Noire, Douala, Kinshasa → fret + douane → **rentable ou non** → brouillon de réponse |
| `rfq-fournisseur` | Demande de prix pro (Chine, Inde, Europe) + tableau comparatif des offres |
| `go-no-go` | Verdict chiffré avant de dépenser 1 € sur une idée, avec test à coût zéro |

## Installation
**Claude (web, desktop, mobile)** : téléchargez le dossier du skill en .zip et ajoutez-le dans la section Skills de vos réglages Claude.

**Claude Code** :
```bash
git clone https://github.com/elvisjunior73-rgb/nelvis-africa-skills.git
cp -r nelvis-africa-skills/skills/* ~/.claude/skills/
```
